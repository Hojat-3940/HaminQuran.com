# HaminQuran.com

نسخه اولیه و قابل توسعه سایت «همین قرآن».

## اجرا

نیازمندی:
- Node.js 18.17 یا جدیدتر
- npm

دستورات:

```bash
npm install
npm run dev
```

سپس مرورگر را روی:

http://localhost:3000

باز کنید.

برای ساخت نسخه production:

```bash
npm run build
npm start
```

## ساختار

- `app/page.tsx` — صفحه اصلی و فهرست سوره‌ها
- `app/quran/[id]/page.tsx` — صفحه هر سوره
- `app/about/page.tsx` — درباره سایت
- `components/` — هدر، تم و فهرست سوره‌ها
- `app/globals.css` — طراحی و حالت تاریک

## داده قرآن

نسخه اولیه برای دریافت داده‌های قرآن از AlQuran.Cloud API استفاده می‌کند.
در این نسخه، متن عربی و ترجمه فارسی از AlQuran.Cloud دریافت می‌شوند و داده صوتی آیات نیز از همان سرویس درخواست می‌شود. قبل از انتشار عمومی، مجوز استفاده از ترجمه، شرایط سرویس داده/صوت، سیاست حریم خصوصی و دامنه نهایی بررسی شود.

## انتشار

این پروژه برای استقرار روی سرویس‌های Node.js/Next.js آماده شده است. پس از نصب وابستگی‌ها، دستور `npm run build` باید روی سرور اجرا شود و در صورت موفقیت با `npm start` اجرا شود.
